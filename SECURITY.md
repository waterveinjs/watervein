# Security Policy

## Supported Versions

Currently, the following versions are supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability in this project, please report it responsibly. **Please do not report security vulnerabilities through public GitHub issues.**

### How to Report
Please use **GitHub Private Vulnerability Reporting** by clicking the "Report a vulnerability" button under the [Security](https://github.com/waterveinjs/watervein/security/advisories/new) tab of this repository.

### Response Policy
- Reports are handled on a **best-effort basis**. We will review and respond to valid reports as time permits.
- Once the vulnerability is verified, we will work on a fix and release a patch when ready.
- You will be notified when the issue is resolved or if further information is needed.

Thank you for helping keep this project secure!
